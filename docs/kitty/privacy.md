# Privacy

Kitty runs on your computer.

- **Usage data**: Kitty collects none. The analytics inherited from T3 Code are off by default and
  are only sent if you set `T3CODE_TELEMETRY_ENABLED=true` yourself.
- **Updates**: the desktop app's automatic update is off. Kitty has no release feed yet.
- **Your projects**: designs, firmware and threads stay in your project folders and in `~/.kitty`.
- **Agents**: the agent CLIs you connect (Claude Code, Codex and others) send your prompts and the
  files they read to their own providers, under those providers' terms.
- **Parts**: looking up or importing a part contacts the JLC / LCSC catalog with the part number.
- **Optional services**: features inherited from T3 Code that use T3's cloud (T3 Connect, the
  mobile app, the GitHub app) only contact it if you sign in to them. Their use is covered by
  [T3 Code's privacy policy](https://t3.codes/privacy-policy).
