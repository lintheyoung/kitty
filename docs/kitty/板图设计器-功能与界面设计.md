# Kitty 板图设计器：功能与界面设计

2026-11-11 · 状态：方案，待确认后按里程碑实现

## 1. 目标

**常见的板子在 Kitty 里能画完。** 面向初学者：大部分操作由 AI 完成，用户只做少量简单的手动调整。
画图界面是 Kitty 原生的，KiCad 只做后端（文件格式、ERC/DRC、铺铜、生产文件、3D 渲染）。

"常见的板子"的范围：

- 2 层板或 4 层板，尺寸 100 × 100 mm 以内，器件 100 个以内
- 4 层板用固定叠层：顶层信号、内层 1 整层 GND、内层 2 电源、底层信号，只用通孔过孔
- 一个主控（ESP32 模组或开发板）加外设：传感器、屏幕、按键、LED、电机驱动、接插件
- 电源：USB-C、LDO、锂电池充电
- 在嘉立创打板和贴片

不在范围内：6 层以上、DDR 和千兆以上的高速接口、射频天线设计、盲埋孔、自己画符号和封装。
遇到这些情况，Kitty 提示用 KiCad 打开同一个工程继续做。

## 2. 界面布局

硬件产品进入"设计模式"后，画布在左，对话在右：

```
┌────────┬──────────────────────────────────────────┬──────────────────┐
│ 侧边栏 │ 需求 › 原理图 › 布局 › 布线 › 检查 › 下单 │ 对话             │
│ 项目   ├──────────────────────────────────────────┤                  │
│ 线程   │ [原理图] [PCB] [3D] [固件与测试]         │ AI：我加了 USB-C │
│        │ ┌──┐                                     │ 和 3.3V 稳压，   │
│        │ │工│                                     │ 改动已在图上标出 │
│        │ │具│          画 布                      │ [接受] [撤销]    │
│        │ │条│                                     │                  │
│        │ └──┘                          ┌────────┐ │                  │
│        │                               │ 属性   │ │                  │
│        │                               └────────┘ │ ┌──────────────┐ │
│        │ 问题 3 · 未连接 2 · 网格 1.27            │ │ 输入框       │ │
└────────┴──────────────────────────────────────────┴─┴──────────────┴─┘
```

- **顶部步骤条**：需求 → 原理图 → 布局 → 布线 → 检查 → 下单。显示当前做到哪一步，每一步有"让 AI 做这一步"按钮。
- **画布标签**：原理图、PCB、3D、固件与测试（现有 Hardware 面板的内容移到最后一个标签）。
- **工具条**：只放本文列出的少数工具，竖排在画布左侧。
- **属性面板**：选中东西时才出现，浮在画布右下。
- **状态栏**：问题数、未连接数、网格。点问题数打开问题列表。
- **对话**：就是现有的线程对话，移到右栏。选中画布上的器件或网络后，输入框上方显示"正在讨论：U1、3V3"，AI 知道你指的是什么。
- 视觉沿用 Kitty 现有的主题、字体、按钮和面板样式；画布配色用主题变量，支持深色和浅色。
- 非硬件项目保持现在的布局不变。

## 3. 功能清单

每项标出谁来做：**AI** 表示默认由 AI 完成，**手动** 表示用户也能自己动手。

### 3.1 通用

| 功能                             | 说明                                                          |
| -------------------------------- | ------------------------------------------------------------- |
| 缩放、平移、适应窗口             | 滚轮缩放，拖动平移                                            |
| 选择                             | 点选、框选；选中后显示属性                                    |
| 移动、旋转、镜像、删除、复制粘贴 | 快捷键与 KiCad 一致（R 旋转、M 移动、Del 删除）               |
| 撤销 / 重做                      | 手动操作和 AI 改动都能撤销                                    |
| 原理图 ↔ PCB 互相定位            | 在一边选中器件或网络，另一边同步高亮                          |
| 问题列表                         | ERC/DRC 的错误标在图上，用大白话解释，每条带"让 AI 修"按钮    |
| AI 改动预览                      | AI 的改动以差异显示（新增绿色、删除红色），用户保留或一键还原 |

### 3.2 原理图

| 功能               | 谁做      | 说明                                                                    |
| ------------------ | --------- | ----------------------------------------------------------------------- |
| 按需求生成电路     | AI        | "加一个 USB-C 供电和 3.3V 稳压"，AI 放器件、连线、填参数                |
| 选器件             | AI + 手动 | 只从嘉立创选：按名称、功能或料号搜索；有库存优先，基础库优先于扩展库    |
| 封装分配           | AI        | 从嘉立创导入时符号、封装、3D 模型一起带进来，用户不需要接触封装分配     |
| 位号编号           | 自动      | R1、C1、U1 自动编                                                       |
| ESP32 引脚分配     | AI        | 避开启动引脚、Flash 引脚等不能随便用的脚，与固件 `pinmap.json` 保持一致 |
| 放器件、连线       | 手动      | 点引脚开始连线，自动走直角                                              |
| 网络标签、电源符号 | 手动      | 3V3、GND、VBUS 等；同名标签自动相连                                     |
| 不连接标记         | 手动      | 标出故意悬空的引脚                                                      |
| 改参数             | 手动      | 阻值、容值、料号                                                        |
| ERC                | 自动      | 保存后自动运行                                                          |

不做：层次图纸、总线、仿真、符号编辑器、批量字段编辑。

### 3.3 PCB

| 功能             | 谁做      | 说明                                                       |
| ---------------- | --------- | ---------------------------------------------------------- |
| 从原理图同步     | 自动      | 原理图改了，PCB 自动添加或更新封装和网络                   |
| 板框             | AI + 手动 | 输入长宽和圆角，或选预设；可加安装孔                       |
| 自动布局         | AI        | 按功能分组摆放：接口靠边、去耦电容靠近芯片、天线留出净空   |
| 摆放             | 手动      | 拖动、旋转、翻到背面；显示飞线                             |
| 自动布线         | AI        | 一键布完全部或剩余的网络                                   |
| 手动走线         | 手动      | 点焊盘开始走线，自动绕开障碍；V 键打过孔换层               |
| 线宽             | 自动      | 按网络类别自动取值：信号线、电源线                         |
| 差分对           | AI + 手动 | USB、MIPI、CAN、以太网等；按 `_P`/`_N` 命名自动识别成对    |
| 差分线宽线距     | 自动      | 按嘉立创叠层和目标阻抗（90 Ω、100 Ω）自动取值              |
| 差分走线         | AI + 手动 | 两根线成对一起走，保持间距；换层时成对打过孔               |
| 等长             | AI        | 显示每根线和每对线的长度及差值；自动加蛇形线补长           |
| 高速信号检查     | 自动      | SPI、SDIO 等：限制长度、要求下方有完整地平面，不合格时提示 |
| 层数             | 手动      | 新建时选 2 层或 4 层，之后可以从 2 层升到 4 层             |
| 铺地             | 一键      | 2 层板正反两面铺 GND；4 层板内层分别铺 GND 和电源          |
| 丝印文字         | 手动      | 板名、版本号                                               |
| DRC              | 自动      | 保存后自动运行                                             |
| 3D 预览          | 自动      | 由 KiCad 渲染                                              |
| 一键出嘉立创文件 | 一键      | Gerber、BOM、贴片坐标，打包成可直接上传的文件              |

不做：推挤走线、6 层以上、盲埋孔、封装编辑器、自定义设计规则编辑器。

## 4. 技术方案

- **数据**：KiCad 文件（`.kicad_sch`、`.kicad_pcb`）是唯一的事实来源。同一个工程随时可用 KiCad 打开。
- **渲染**：Kitty 自己的画布组件，解析 KiCad 文件后绘制。参考开源项目 KiCanvas（MIT 许可）的解析和绘制方法。
- **编辑操作层**：所有修改都是一组有名字的操作（放器件、连线、移动、走线等）。
  用户的鼠标操作和 AI 的工具调用走同一套操作，所以撤销、差异预览、校验对两者一致。
- **后端**：`kicad-cli` 负责 ERC、DRC、网表、3D 渲染和生产文件；铺铜用 KiCad 的 `pcbnew` Python 接口；自动布线用开源的 Freerouting。
- **器件库**：板上每个器件都来自嘉立创，都带立创料号（如 C25804）。
  搜索走嘉立创的贴片器件目录；导入时用 `easyeda2kicad` 把符号、封装、3D 模型转成 KiCad 格式，
  放进工程自己的 `lib/jlc` 库（`jlc.kicad_sym`、`jlc.pretty`、`jlc.3dshapes`）。
  唯一的例外是电源符号（GND、3V3 等），它们不是实际器件，用 KiCad 自带的。
  `easyeda2kicad` 是 AGPL 许可，Kitty 只把它当外部命令调用，不打包它的代码。
- **校验**：每次写文件后用 `kicad-cli` 重新读一遍，确认 KiCad 能正确打开；测试里对样例工程做读写往返比对。

## 6. 风险

- 写出的文件必须保证 KiCad 能打开：靠第 4 节的校验和往返测试控制。
- 自动布局和自动布线的质量对初学者体验影响最大，需要用真实的板子反复调。
- 手动走线的"自动绕开障碍"是最复杂的单项功能；M4 先做能用的简单版本。
- 差分成对走线和蛇形等长是第二复杂的功能，单独放在 M5；阻抗值依赖嘉立创的叠层参数，需要按板厚和层数维护一张表。
